# Keyboard shortcuts
{: .no_toc }

Cellar uses Excel's shortcuts. Every menu item shows its shortcut, and
**Help → Keyboard Shortcuts & Formulas** (F1) lists them all inside the
program.

On macOS, **⌘** replaces Ctrl for the common commands (⌘C, ⌘S, ⌘Arrow…).
Save As is ⌘⇧S, AutoSum is ⌘⇧T and Quit is ⌘Q, as in Excel for Mac.

## Editing

| Keys | Action |
|---|---|
| Type | Start editing the cell (replaces its content) |
| F2 or double-click | Edit the cell's current content |
| Enter / Shift+Enter | Finish and move down / up |
| Tab / Shift+Tab | Finish and move right / left |
| Ctrl+Enter | Finish and fill every selected cell |
| Esc | Cancel the edit; also removes tracer arrows and cancels Format Painter |
| Tab, while typing a formula | Insert the highlighted function or name |
| Delete | Clear the selected cells |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+; / Ctrl+Shift+; | Insert today's date / the current time |
| Shift+F2 | Edit comment |
| Ctrl+K | Insert link |

## Moving and selecting

| Keys | Action |
|---|---|
| Arrows, PgUp, PgDn | Move |
| Ctrl+Arrow | Jump to the edge of the data |
| Home | First column of the row |
| Ctrl+Home / Ctrl+End | First cell / last used cell |
| Shift + any of the above | Extend the selection |
| Shift+Space / Ctrl+Space / Ctrl+A | Select row / column / all |
| Ctrl+G or F5 | Go To |
| Ctrl+F / Ctrl+H | Find / Replace |

## Clipboard and fill

| Keys | Action |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+Alt+V | Paste Special |
| Ctrl+Shift+V | Paste values |
| Ctrl+D / Ctrl+R | Fill down / fill right |

## Rows and columns

| Keys | Action |
|---|---|
| Ctrl+Shift+= | Insert (whole rows or columns when they are selected) |
| Ctrl+- | Delete |
| Ctrl+9 / Ctrl+Shift+9 | Hide / unhide rows |
| Ctrl+0 / Ctrl+Shift+0 | Hide / unhide columns |

## Formatting

| Keys | Action |
|---|---|
| Ctrl+B / Ctrl+U | Bold / underline |
| Ctrl+Shift+~ | General format |
| Ctrl+Shift+! | Number format |
| Ctrl+Shift+$ | Currency format |
| Ctrl+Shift+% | Percent format |
| Ctrl+T | Format as Table |

## Formulas and data

| Keys | Action |
|---|---|
| Alt+= | AutoSum |
| F9 | Calculate now |
| Ctrl+` | Show formulas |
| Ctrl+F3 | Name Manager |
| Ctrl+Shift+L | Filter |
| Alt+F1 | Insert chart |
| Ctrl+click on a link | Open the link |

## Sheets, files and view

| Keys | Action |
|---|---|
| Shift+F11 | Insert sheet |
| Ctrl+PgDn / Ctrl+PgUp | Next / previous sheet |
| Ctrl+N / Ctrl+O | New / open |
| Ctrl+S / F12 | Save / Save As |
| Ctrl+P | Print (opens the sheet as a PDF) |
| Ctrl + mouse wheel | Zoom |
| F1 | Keyboard shortcuts and formulas |
